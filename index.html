🎨 Change the color

Color isn't a prop — every game reads the --spinner-color CSS custom property. Set it on the element (or any ancestor) and it cascades in. Because it's plain CSS, it works the same in HTML, React, Vue and Angular. Try the swatches:

Pick a color

In a stylesheet — recolors every game on the page

spinner-bubbles {
  --spinner-color: #2caac3;
}

Or inline, on a single instance

<spinner-bubbles style="--spinner-color: #2caac3"></spinner-bubbles>

Every game is themeable with the --spinner-color CSS variable and sizes itself to its container — see docs/ for the full reference.
